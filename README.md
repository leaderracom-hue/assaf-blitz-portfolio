# Assaf Blitz · Interactive portfolio

Seven AI products, from lead to meeting. A Streamlit page where each product can be explored step by step,
with a "Try it" panel that plays the product's own rules.

The numbers come from a pilot (about 25 live leads and 22 meetings) and are marked as a small sample.
The "Try it" panels are illustrations computed in the page, not calls to the real systems.

Run locally:

```bash
pip install -r requirements.txt
streamlit run app.py
```
